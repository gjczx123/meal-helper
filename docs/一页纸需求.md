# 三餐助手 · 一页纸需求（v1.0）

## 一、一句话

每天 08:30 / 12:30 / 18:30 自动在微信提醒她报备三餐；她回文字或照片，系统自动读取、
按 7 天轻断食菜单严格判定、记账并轻提醒；全程无人值守，关掉窗口也在后台跑。

## 二、用户

- **她**：被提醒的人，知情并接受。以打字为主，偶尔拍照，会回「没吃」。
- **你**：装软件、维护菜单、看记录的人。只有一个她，不做第二个人。

## 三、必须做到（P0）

| # | 需求 | 标准 |
|---|---|---|
| 1 | 定时提醒 | 三个时间可改，改完立即生效 |
| 2 | 读取回复 | 文字/图片，30 分钟内到达即处理 |
| 3 | 严格判定 | 计划内不超量=合规；超量=超；计划外=超；没吃=未进食；看不懂=未识别 |
| 4 | 轻提醒 | 超标只说一句人话，不报热量、不报份数、不列清单、不催 |
| 5 | 记录 | 每顿一条：原文/照片/判定/回复；存 2 个月自动清理 |
| 6 | 可视化 | 双击 exe 打开，五页：今日 / 记录 / 餐标 / 设置 / 诊断 |
| 7 | 餐标可改 | 7 天菜单表格化编辑，保存即生效 |
| 8 | 常驻可靠 | 单实例、日志、失败通知、开机自启、托盘常驻 |
| 9 | 不误发 | 发送前后双重校验收件人，不符立即停 |

## 四、明确不做

- 不做热量计算、不做营养建议（只对照菜单，不算卡路里）
- 不做语音转文字（语音只记一条，不回复）
- 不做追问、不做催问、不做多轮对话
- 不做多联系人、群聊、家人朋友复用
- 不做手机端、网页版、云同步（数据只在本地）
- 不做体重、运动、喝水、吃药记录
- 不自动改菜单、不自动替她点餐、不读外卖小票
- 不做表情包、视频、文件、小程序卡片
- 不做微信以外的任何渠道

## 五、主流程

### A. 安装与首次启动
1. 双击 exe → 向导
2. 填她的微信备注 → 检测微信是否在运行 → 发一条测试消息到文件传输助手
3. 设 DAY1 起始日 + 三餐时间 → 勾「保持不锁屏」→ 完成
4. 常驻托盘，关窗口不退出

### B. 每天一顿（核心循环）
1. 到点 → 检查会话是否锁屏、微信是否在线
2. 发提醒：校验会话标题 → 粘贴 → 回车 → **读库确认已送达**
3. 进入 30 分钟等待窗，每 15 秒读一次库
4. 有新消息 → 取最新（多条合并）→ 解析
5. 判定 → 记账 → 回一句（未识别不回）
6. 窗口结束仍无 → 记「未报备」，托盘黄点
7. 任何异常 → 写日志 + 弹通知，不影响下一顿

### C. 日常维护
- 改时间 / 改菜单 → 保存即生效，不用重启
- 看记录 → 记录页按天翻
- 周日 20:00 → 周报发到你的文件传输助手

## 六、验收标准

### 6.1 功能验收（逐条勾）
- [ ] 三个时间都能改，改完当天立即按新时间触发
- [ ] 菜单能增删改，保存后下一次判定就用新菜单
- [ ] 她回文字，30 秒内被记录并回复
- [ ] 她回照片，能存下并识别出量与菜品（允许不精确）
- [ ] 她回「没吃」，记为未进食，不警告、不催
- [ ] 她说的不在计划内，判超标并轻提醒
- [ ] 计划内吃两份，判超标
- [ ] 看不懂，只记原文，不回复
- [ ] 记录页能看到原文、照片、判定、回复，能改判定
- [ ] 关窗口后托盘还在，到点照样提醒
- [ ] 没有 Python 的电脑双击 exe 能开

### 6.2 质量指标
| 指标 | 标准 |
|---|---|
| 判定准确率 | ≥ 95%（30 条人工标注样本） |
| 回复延迟 | 她发出 → 我们回信 ≤ 30 秒 |
| 发送耗时 | ≤ 3 秒（含抢前台与还原） |
| 3 天 9 顿连续跑 | 发送成功率 100%，重复发送 0，发错人 0 |
| 崩溃 | 连续 3 天无未捕获异常 |

### 6.3 边界用例（必须全过）
| 场景 | 期望 |
|---|---|
| 到点时电脑锁屏 | 记未提醒 + 通知，解锁后 30 分钟内补发 |
| 微信没开/没登录 | 不发不猜，通知你，等下一餐 |
| 她换了微信备注 | 改设置里的备注后恢复正常 |
| 23:59 才回复 | 仍归到当天那一餐 |
| 她连发 5 条 | 合并成一次，只回一次 |
| 她发语音 | 记一条「语音」，不回复 |
| 照片模糊 | 存图、标未识别、不回复 |
| 重复双击 exe | 第二个实例自动退出 |
| 断网 | 判定照常（本地），图片识别降级 |
| DAY1 起始日改了 | 立即按新日期算今天该吃哪套 |
| 记录超 2 个月 | 自动清理，界面不报错 |
